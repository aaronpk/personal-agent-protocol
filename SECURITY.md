# Security

## Reporting a vulnerability

Report anything that could harm a live implementation privately, through
[GitHub's private vulnerability reporting](https://github.com/personal-agent-protocol/personal-agent-protocol/security/advisories/new).
This covers:

- Weaknesses in the specification or an extension that an attacker could use against Personal
  Agents, Companies, or Users, such as a way to get or reuse tokens, act on an account without
  approval, or link Users across Companies.
- Vulnerabilities in this site.
- Problems in the agent kit, including its validator, that could lead implementers to ship an
  insecure implementation.

Don't open a public issue, pull request, or discussion for these. Include the part of the docs or
code affected, how it could be used, and a suggested fix if you have one.

## Security questions in public

Questions and suggestions about the protocol's security design that don't expose a weakness in a
live implementation are welcome as public
[feedback](https://github.com/personal-agent-protocol/personal-agent-protocol/issues/new?template=1-feedback.yml).
If you aren't sure, report privately.
